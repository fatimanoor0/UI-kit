Reusable UI Kit

A small UI kit built with HTML, CSS, and Vanilla JavaScript.

Components

- Reusable Buttons with different variants
- Reusable Cards with different content
- Functional Modal with open/close
- Toast Notifications with auto-dismiss and stacking

Concept

This project focuses on thinking in components. Instead of repeating HTML code, each UI element is created using a reusable JavaScript function with different inputs. This makes the code cleaner, reusable, and easier to maintain.

Technologies

- HTML
- CSS
- JavaScript
